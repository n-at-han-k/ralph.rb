# Plans

This directory contains implementation plans for Ralph.rb features and tasks.

Plans are distinct from specs: a **spec** describes the design and intended behaviour of a component, while a **plan** describes the concrete steps to build or change something.

## Directory structure

Each plan is a Markdown file with a 4-digit sequential prefix:

```
plans/
  0001_ruby_conversion.md
  0002_output_extraction.md
```

When creating a new plan, use the next available number. For example, if the highest existing prefix is `0002`, name your file `0003_your_plan_name.md`.
